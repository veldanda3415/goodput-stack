## Assumptions (explicit inputs, not sourced)

| ID | Assumption | Default | Why this default | What changes if wrong |
|---|---|---|---|---|
| A1 | Achieved network bandwidth efficiency (fraction of NIC line rate that a large collective achieves) | 0.80 | Leaves headroom for headers, protocol overhead and imperfect load balance; no vendor publishes one number for every system | Every scale-out time scales by 1/efficiency |
| A2 | Achieved NVLink efficiency | 0.80 | Same reasoning as A1 | NVLink times scale by 1/efficiency |
| A3 | Per-step latency α, scale-out | 5 µs | Order of an RDMA round trip through a leaf-spine fabric plus software; only matters for small messages | Small-message (latency-bound) times only |
| A4 | Per-step latency α, NVLink | 1 µs | Same | Same |
| A5 | Model FLOP utilisation (MFU) for the compute-time estimate | 0.40 | A middle value for large dense training; used only to put communication time against compute | Job-level slow-link slowdown (a lower MFU → longer compute → smaller relative slowdown) |
| A6 | No overlap of communication with compute | overlap = 0 | Worst case; real frameworks overlap DP gradient traffic with backward compute | Job-level slowdown is an upper bound |
| A7 | Nodes per rack | 4 | 4 × 10.2 kW (S1) ≈ 41 kW; rack power budget is a site decision | Which NIC-to-leaf links can be copper |
| A8 | Rack-to-rack and leaf-to-spine runs exceed 3 m | yes | Spines sit in a separate network row; S19 caps passive copper at 3 m | Transceiver count |
| A9 | Mixtral-8x7B shape: 32 layers, d 4,096 | — | Mistral-7B shape; not on the abstract page (S18) | Size of the MoE example only |
| A10 | Front-end oversubscription | 3:1 | Front-end carries north-south and storage-access traffic, not collectives; not stated in S10 | Front-end spine count |
| A11 | Front-end minimum spine count | 2 | One spine failure must not isolate the front-end | Front-end spine count at small scale |
| A12 | One 1G management port per fabric switch on the OOB network | 1 | Typical for managed switches; not stated in S6/S8/S10 | OOB switch count (small) |
